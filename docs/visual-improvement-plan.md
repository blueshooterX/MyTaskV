# ビジュアル改善計画 (v1.6.0)

## 目的
タスクがあまりクローズされず「更新」が中心の運用でも、「やっている感」が得られるUIにする。

## データ変更
- TaskList に J列「最終更新日時」(`COLUMNS.UPDATED_AT: 9`) を追加。J1 が空なら `getData` 時に自動補完。
- ActivityLog シートを新設: `日時 / タスクID / 種別 / タイトル`。初回書き込み時に自動作成。
  - 種別: `create` / `update` / `complete` / `reopen` / `move`
- `saveTask`: 常に最終更新日時を記録しログ追記（ラベル・期限・優先度の変更も「更新」にカウント）。
- `updateOrderAndStatus`: ステータスが変わった行のみ記録（並び順のみの変更は対象外）。
- `getActivity()`: 過去26週の日別件数 + 直近14日のログを返す。

## UI
| ID | 内容 |
|---|---|
| A1 | 保存したカードが光って跳ねる / ヘッダー統計に「+1」 |
| A2 | 本文行頭の `(M/D)` を抽出し、カード下部に進捗ドット（最大7） |
| A3 | 完了時にCSS紙吹雪 |
| A4 | カラムヘッダー下に優先度比率ミニバー |
| B1 | 鮮度表示: 今日=🔥+グロー / 3〜6日=彩度ダウン / 7日以上=薄く、実施中のみ「💤 N日」。完了カラムは対象外 |
| B2 | ヘッダーに「🔥 今日 N ｜ 🗓 N日連続」。クリックでアクティビティパネル |
| B3 | カラムソートに「最近更新」 |
| C1 | 26週ヒートマップ |
| C2 | 週次ふりかえり（今週の更新/完了/新規・先週比・よく触ったTop3） |

## Driveリンクチップ
- Drive / ドキュメント / スプレッドシート / スライド / フォーム / 図形描画 / フォルダのURLを、`[種類アイコン] ファイル名` のチップで表示する（`js-drive-links.html`）。
- サーバー側 `resolveDriveLinks(ids)` がまとめて名前を解決し、`CacheService` にキャッシュする（解決済み6時間 / アクセス不可10分）。
- 保存データはURLのまま（表示時だけ変換）。公開フォームのURL（`/forms/d/e/...`）と Gmail / カレンダー / Meet は従来のアイコン表示。
- `appsscript.json` に `oauthScopes` を明示（`drive.readonly` を追加。自動検出されるDriveのフル権限を避けるため）。デプロイ後に再承認が必要。

## 決定事項
- ラベル・期限・優先度の変更も更新としてカウントする。
- 「💤 N日」バッジは実施中のみ。未着手・保留は彩度ダウンのみ。
- 連続日数は、今日の更新が0でも昨日まで続いていれば維持する。
- 最終更新日時が空の既存行は鮮度スタイルを適用しない。

## 追加調整（フィードバック反映）
- カラム幅のデフォルト比率を 未着手:実施中:保留:完了 = 1:3:1:1 に変更（`COLUMN_FLEX`）。
- 詳細表示をデフォルトONに変更。
- 派手さ強化（第2弾）: 動くグラデーション背景＋すりガラス風カラム、カラムヘッダーをグラデーションで塗りつぶし＋絵文字アイコン、実施中カラムの光彩パルス、今日更新カードの回転する虹色の枠、トースト通知（完了・新規・更新・節目）、保存時のキラキラ、完了時の大きな紙吹雪、今日の更新件数が 3/5/10/20/30/50 に届いたら画面全体に紙吹雪。
- 配色整理（第3弾、上記の派手さ強化を見直し）: パステル系の動く背景・虹色の枠・多色グラデーションは、コントラストが悪く悪趣味に見えたため廃止。紺色ベースの背景＋白いカードで明暗差を確保し、色の役割を「藍=メイン」「オレンジ=今日の鮮度」「ステータス4色=カラムヘッダーのみ」に限定。グループラベルの色は、同じ色相のまま白文字が読める濃さに変更。
- 鮮度バッジはタイトル行を圧迫するため、カード下部のフッター行へ移動。タイトルは2行まで折り返して表示。
- 色の変化を強調: ステータス別カラムテーマ（実施中を強調）、鮮度4段階（今日/1〜2日/3〜6日/7日以上）を背景色・枠線・バッジで明確化、ヘッダー統計はアクティブ時グラデーション。

# モーション・SF調リニューアル (v1.7.0)

デモ（`demo/motion-demo.html`）で検討した演出を本番に反映。

## 決定事項
- トーンは「会社で使える落ち着いたSF調」。第2弾の派手な演出（紙吹雪・トースト連発・絵文字）と第3弾の「紺背景＋白カード」を置き換える。
- 配色: ダーク（紺黒＋暗いカード）とライト（青灰＋白カード）を切り替え可能。既定は「自動」（OSの設定に従う）。アクセントはシアン1色、琥珀=優先度「高」、緑=完了、赤=期限切れ。色はすべて `css.html` のトークンで定義。
- 配色は `localStorage`（`mytask-theme`）に保存し、`index.html` の `<head>` 内スクリプトでスタイル適用前に反映する。
- ラベルは単色記号 `☆(なし) ★ ⚑ ◆ ♥` に変更。既存の絵文字（⭐⚠️💥🩷）は表示時に対応する記号へ読み替え、次にラベルを変更したときに新しい値で保存される。
- ドラッグ＆ドロップは Sortable.js をやめ、自前実装（`js-motion.html`）に置き換え。並び順の保存フロー（保存バナー → `updateOrderAndStatus`）は従来どおり。
- ランク・経験値・本日の目標・実績は ActivityLog（過去26週）から算出し、サーバー変更なし。重み: 新規20 / 更新10 / 移動15 / 完了50 / 差し戻し10、目標達成1つにつき+100。チェインと「待機カードの復帰」「俯瞰」「重力」の実績はブラウザ内のみ。
- 本日の目標: 今日5件更新 / 2件完了 / 1件追加（待機カードの復帰はログに残らないため目標から外した）。
- 重力モードは matter-js 0.19.0 を cdnjs から読み込む。
- 演出は24種（A1〜A6, B1〜B4, C1〜C4, D1〜D10）。メニューの「演出設定」で個別に ON/OFF でき、`localStorage`（`mytask-fx`）に保存。効果音（D8）のみ初期 OFF。OS の「視差効果を減らす」が ON の場合は全演出が初期 OFF。
- 優先度の変更はモーダルからのみ（カード上の優先度チップは追加しない）。B4 は保存時に「高」へ変わったカードで発動。
